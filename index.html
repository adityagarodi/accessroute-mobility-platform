How It Works

From sensor detection to smart rerouting

The complete chain: IoT sensors detect real-world changes → ESP32 transmits data → AI engine recalculates routes → user receives instant guidance.

1
IoT Sensor Detects
ESP32-based sensors monitor elevators, ramps, pathways, and bus stops in real time.
2
Facility Status Updates
Sensor data instantly updates facility availability — obstacle, unavailable, or limited.
3
AI Route Engine
AI recalculates the most accessible route based on your personal accessibility profile.
4
User Guided Instantly
You receive voice + visual guidance, map update, and an alert — all in seconds.
Platform Features

AI + IoT + GIS + Accessibility

Every feature is purpose-built for real-world accessibility challenges in public transport.

IoT Sensor Network

ESP32-based ultrasonic, IR, reed and vibration sensors monitor every accessible facility in real time.

Live Accessibility Map

OpenStreetMap with real-time facility markers, sensor locations, route overlays, and disruption alerts.

AI Route Engine

Accessibility-first route optimization. Prioritizes step-free, elevator, low-floor transport based on your profile.

Automatic Rerouting

When a sensor detects an obstacle or facility failure, the system instantly recalculates your accessible route.

GTFS Transport Data

Real-time low-floor bus, metro and train tracking. Know which vehicles are wheelchair accessible.

Voice + Visual Guidance

Multilingual voice guidance (EN/HI/MR) with visual overlays, high contrast, and reduced motion support.

Accessibility First

Built for every ability

WCAG-conscious design with keyboard navigation, ARIA labels, visible focus states, and reduced motion support throughout.

  • Wheelchair accessible route planning
  • Voice guidance (English, Hindi, Marathi)
  • High contrast and large font modes
  • Reduced motion for vestibular sensitivity
  • Screen reader optimised with semantic HTML
  • Cognitive-friendly simple instructions
